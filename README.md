# telecom-analysis
proyecto tripleten telecom-analysis
# readme
# el objetivo del proyecto
- entender el comportamiento de los clientes de ConnectaTel según edad, volumen de llamadas/mensajes y nivel de consumo, para identificar oportunidades de negocio# los datasets utilizados
-plans.csv, users_latam.csv, usage.csv
# las etapas del análisis realizada
- distribuciones, outliers, segmentación y oportunidades comerciales
# cómo ejecutar el notebook 
- abrir el notebook en jupyter y ejecutar las celdas en orden
# guía de reproducción
- Para ejecutar este proyecto, asegúrate de tener Python y Jupyter instalados. Luego instala las librerías necesarias con el siguiente comando: pip install pandas numpy seaborn matplotlib
